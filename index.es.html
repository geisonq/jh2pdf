HTML a PDF idéntico al navegador, sin navegador en el servidor. El navegador mide el diseño; PHP solo dibuja el PDF.

Galería de ejemplos →Tablas, degradados, sombras, imágenes con filtros, listas, marcas a mano y una factura, con el PDF generado. Documentación →Instalación, API JS y PHP, CSS soportado, fuentes, seguridad, rendimiento y dependencias. Ejemplo mínimo →El código más pequeño posible: una página HTML y un endpoint PHP.

¿Por qué Jh2Pdf?

  • Sin navegador en el servidor. Una alternativa ligera a Chrome headless, Puppeteer y wkhtmltopdf: sin VPS, contenedores ni binarios.
  • Igual que la pantalla. A diferencia de Dompdf, mPDF o TCPDF leyendo el HTML, soporta flexbox, grid, variables CSS, degradados y filtros de imagen, porque el diseño lo calcula el navegador.
  • PDF de verdad. Texto seleccionable y buscable, fuentes incrustadas y 12 familias de fuentes libres incluidas.
  • Seguro por diseño. El servidor nunca interpreta HTML, CSS ni JavaScript: solo dibuja números, colores y texto validados.

Instalación

composer require geisonq/jh2pdf

Después, copia js/jh2pdf.js a tu sitio. Código fuente en GitHub · paquete en Packagist.
