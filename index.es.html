Jh2Pdf

HTML a PDF idéntico al navegador, sin navegador en el servidor. El navegador mide el diseño; PHP solo dibuja el PDF.

Galería de ejemplos →Tablas, degradados, sombras, imágenes con filtros, listas, marcas a mano y una factura, con el PDF generado. Documentación →Instalación, API JS y PHP, CSS soportado, fuentes, seguridad, rendimiento y dependencias. Ejemplo mínimo →El código más pequeño posible: una página HTML y un endpoint PHP.
