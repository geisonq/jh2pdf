Each card below is an A4 page made with nothing but HTML and CSS. The browser measures the layout, js/jh2pdf.js turns it into drawing operations and PHP (demo/pdf.php) draws the PDF. Generate the PDF and compare it with the preview: they should match.

Live generation needs a server with PHP. On a static site (like GitHub Pages), the buttons open the ready-made PDF, generated earlier from this same page with Jh2Pdf.

1. HTML + CSS2. extractLayout() in the browser3. POST the JSON4. Renderer::render() → PDF
