Fonts in this folder / Fontes desta pasta

Static TTF instances (weights 400-700) generated from the original variable fonts by tools/generate-fonts.py, used only on the
server to embed the fonts (subset) in the PDFs.
Instâncias TTF estáticas (pesos 400 a 700) geradas das fontes variáveis originais por tools/generate-fonts.py, usadas só no
servidor para embutir as fontes (subconjunto) nos PDFs.

Four families have a Reserved Font Name. Static instances are Modified Versions, so they were renamed
(family names inside the files and file names); their original copyright notices are kept below.
Quatro famílias têm nome reservado. As instâncias estáticas são versões modificadas, por isso foram renomeadas
(nomes dentro dos arquivos e nomes dos arquivos); os avisos de copyright originais seguem abaixo.
