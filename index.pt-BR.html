HTML para PDF fiel ao navegador, sem navegador no servidor. O navegador mede o layout; o PHP só desenha o PDF.

Galeria de exemplos →Tabelas, degradês, sombras, imagens com filtros, listas, marcas à mão e uma fatura, com o PDF gerado. Documentação →Instalação, API JS e PHP, CSS suportado, fontes, segurança, desempenho e dependências. Exemplo mínimo →O menor código possível: uma página HTML e um endpoint PHP.

Por que o Jh2Pdf?

  • Sem navegador no servidor. Uma alternativa leve ao Chrome headless, ao Puppeteer e ao wkhtmltopdf: sem VPS, container nem binários.
  • Igual à tela. Diferente do Dompdf, mPDF ou TCPDF lendo o HTML, suporta flexbox, grid, variáveis CSS, degradês e filtros de imagem, porque quem calcula o layout é o navegador.
  • PDF de verdade. Texto selecionável e pesquisável, fontes embutidas e 12 famílias de fontes abertas incluídas.
  • Seguro por desenho. O servidor nunca interpreta HTML, CSS nem JavaScript: só desenha números, cores e texto validados.

Instalação

composer require geisonq/jh2pdf

Depois, copie o js/jh2pdf.js para o seu site. Código-fonte no GitHub · pacote no Packagist.
