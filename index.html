Jh2Pdf

HTML para PDF fiel ao navegador, sem navegador no servidor. O navegador mede o layout; o PHP só desenha o PDF.

Galeria de exemplos →Tabelas, degradês, sombras, imagens com filtros, listas, marcas à mão e uma fatura, com o PDF gerado ao vivo. Documentação →Instalação, API JS e PHP, CSS suportado, fontes, segurança, desempenho e dependências. Exemplo mínimo →O menor código possível: uma página HTML e um endpoint PHP.
